# Promo video

Renders the Cursor FX videos and the README media from the real shaders in `../shaders/`.
The published video is **the showcase cut** (below, 56 s, 4K, original music made by
`music/compose.py`). Every frame comes from the shaders: every effect frame is the actual GLSL running on a
painted terminal screen with Ghostty's uniforms (the same setup as `../test/index.html`
and the `cursor-fx edit` preview). Nothing is animated by hand except the captions.

## What you need

- Node 18+, Google Chrome (driven headless through `playwright-core`; no browser download), ffmpeg.
- Python 3 for `capture-panel.mjs` (it runs `../bin/cursor-fx edit` on a throwaway config copy).
- For the showcase cut: Python 3.12 via `uv` (numpy, scipy, pedalboard, soundfile, pyloudnorm) to make its music.
- For the older main and trio cuts only: a song of your own as `audio/song.wav` (see Music).
- Optional: the TX-02 font installed (the terminal text uses it, falling back to Menlo).

## Re-render

```sh
cd promo
npm install                      # playwright-core only
node capture-panel.mjs           # panel footage -> capture/panel/ (redo when the panel changes)
node render.mjs sheet            # contact sheet of key moments -> out/sheet.png (check this first)
node render.mjs video            # the video -> out/cursor-fx-promo.mp4 (3 parallel chunks, ~3 min on an M1)
node render.mjs readme           # ../media/lightning-enter.gif + .mp4, ../media/effects/<name>.png
```

### The trio cut (lightning, cyber, glitch; 39 s, 4K)

```sh
node render.mjs sheet 12.31 23.1 34.36 --cut trio   # check moments
node render.mjs video --cut trio                     # out/cursor-fx-trio-4k.mp4 + cursor-fx-trio-1080p.mp4
```

Storyboard in `js/trio.js`, motion (zoom punches, shake, color split, glitch slices,
whip / glyph-rain / slice transitions, the lightning streak) in `js/post.js`, driven by the
`HITS` list. It renders at 3840×2160 with the shaders running at that size, and the page
POSTs each frame as a PNG to render.mjs. The 1080p file is scaled down from the 4K master.
It renders with one job (~9 min on an M1): three parallel 4K jobs ran an 8 GB Mac out of
memory and froze it, so don't pass `--jobs` above 1 for this cut.

### The showcase cut (all thirteen, own music; 56 s, 4K)

The release video. Original music, generated by `music/compose.py` (no samples or loops, so it can
be published anywhere), on the same grid as the storyboard (`js/showcase-grid.js`: 120 BPM, bar 0
at video time 0). Its sound effects (key clicks, each effect's Enter sound, the done swells, the
whooshes) are placed from the storyboard's own cue list, so they land on the frames.

```sh
node capture-showcase-panel.mjs                      # panel footage -> capture/showcase-panel/ (redo when the panel changes)
node render.mjs cues --cut showcase                  # out/showcase_cues.json: keystrokes, Enter, done, cuts
uv run --with numpy,scipy,pedalboard,soundfile,pyloudnorm python music/compose.py   # audio/showcase.wav (-14 LUFS, < -1 dBTP)
node render.mjs sheet 8.3 16.6 28.3 45.8 --cut showcase   # check moments
node render.mjs video --cut showcase                 # out/cursor-fx-showcase-4k.mp4 + cursor-fx-showcase-1080p.mp4 (one job, ~15 min on an M1)
```

Change the storyboard (`js/showcase.js`) → run `cues` and `compose.py` again so the sounds follow.
`node social-card.mjs` draws the repository's social preview (`out/social-preview.png`, 1280×640;
upload it under Settings → Social preview).
Change only the music → `compose.py`, then `node render.mjs mux --cut showcase` (about a minute: it
joins the rendered picture, `out/showcase_chunk_0.mp4`, with the new track; nothing is re-rendered).
Chapters: five living cursors and the prompt (0-8 s), the drop with the title (8), lightning
(typing, delete-all, Enter), cyber (typing, Enter, your text), glitch (typing, Enter, done, the
cursor; stutter and tape stop), the settings panel and zsh (break, 24-28), mecha (Enter on the
second drop, thrusters both ways, the prompt mark's lock-on, done), neon, the other seven on the
beat, all thirteen at once, the install and the end card (48-56).

### Chunks

`video` renders `out/chunk_0..2.mp4` and then joins them with the song. If one chunk fails
or you change only part of the video, redo that chunk and join again:
`node render.mjs chunk 3096 4643 out/chunk_2.mp4 && node render.mjs mux` (chunk k covers
frames `k*1548` to `(k+1)*1548`).

Check the result: `node render.mjs events` writes the song time of every cut and Enter/done
hit to `out/events.json`; the music-sync skill's `sync_check.py out/cursor-fx-promo.mp4
--events out/events.json --start 34.955 --source <song resampled to 44.1 kHz>` reports how
many frames each one is off, and the audio offset.

`node render.mjs stills 12.3 24.6` writes single frames; open
`index.html?t=24.6` (served from the repo root) to look at one moment in a browser.

When a shader changes, just run `video` and `readme` again: the frames come from the
shader files. `capture-panel.mjs` copies your `~/.config/ghostty/config` and `themes/`
into a temp folder with the repo's shaders and presets, so your installed files are
never touched and Ghostty is not reloaded.

## Where things are

| File | What |
| --- | --- |
| `js/scenes.js` | the storyboard: every shot, its keystrokes / Enter / done times, captions, the GitHub URL (`URL_TEXT`) |
| `js/timeline.js` | the music grid (BPM, where the drop is, where video time 0 sits in the song) |
| `js/effects.js` | effect colors and the caption wording (from the README table) |
| `js/term.js` | the painted terminal: Claude Code and zsh screens, Graphite theme |
| `js/fx.js` | runs a shader with Ghostty's uniforms |
| `js/comp.js` | window chrome, background, captions |

## Music

The main and trio cuts were timed to a commercial song that isn't part of this repository
(no rights to publish it); `js/timeline.js` holds its grid. To render them, put a song you
may use in `audio/song.wav` and set its grid there. The showcase cut needs none of this: its
music is generated, see above.

Measured from the original song (librosa / transient fits): 117.07 BPM (a bar is 2.0501 s); the
drop's bass starts at 47.24 s; the female vocal enters at about 36.7 s. Video time 0 is
song 34.955 s, six bars before the drop, so the voice comes in 1.7 s into the video and
the drop lands at 12.30 s, where the lightning Enter fires. Cuts sit on bar lines after
that; typing keystrokes fall on 8th or 16th notes. The video ends at 77.4 s, in the quiet
break before the second drop, with a 1.6 s audio fade.
